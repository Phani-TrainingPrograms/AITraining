Key Capabilities & Implementation Details

🔐 Secure Key Management

Replaced hardcoded API keys with python-dotenv. The script dynamically reads GOOGLE_API_KEY from .env with validation.

💬 Multi-Turn Chat Memory

Leverages client.chats.create() to maintain full conversation context across turns, enabling follow-up questions.

🌊 Real-Time Streaming

Responses stream token-by-token via chat.send_message_stream(), delivering zero-latency responsive output.

🚪 Clean Exit Handling

Gracefully terminates the chat loop upon receiving exit commands (quit, bye, exit) or interrupt signals.

Ex03 — Tkinter Desktop Chatbot UI

ui.py provides a desktop window powered by Python's built-in tkinter library. It calls the same Gemini backend used in Ex03.py while adding a short-term memory window, colour-coded messages, and a clean dark-mode design.

🎨 Colour-Coded Messages

User queries are displayed in red-pink, bot replies in blue. Each conversation turn is separated by a blank line for easy reading.

🧠 Short-Term Memory (3 turns)

A deque(maxlen=3) keeps the last 3 user/bot exchanges and prepends them as context on every new request — giving the bot conversational awareness without an unlimited history.

📐 90 / 10 Layout

The window uses a grid layout where the chat display occupies 90% of the height and the input row occupies 10%, matching the reference wireframe.

📏 Half-Screen Launch

On startup the window automatically centres itself at exactly half the screen width and height, adapting to any monitor resolution.

🚀

How to Run the Tkinter UI (Ex03)

1. Activate virtual environment & install dependencies

# Windows PowerShell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

2. Ensure your API key is in .env

GOOGLE_API_KEY=your_gemini_api_key_here

3. Launch the UI

python ui.py

4. (Optional) Run the terminal bot

python Ex03.py
